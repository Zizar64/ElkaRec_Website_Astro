# ATTENTION : ce fichier n'est pas seul à décider de ce que reçoivent les
# robots.
#
# Cloudflare injecte un bloc « managed robots.txt » (dashboard → AI Crawl
# Control) AVANT le contenu ci-dessous. Constaté le 22/08/2026 : ce bloc
# posait un « Disallow: / » sur une dizaine de robots d'IA (Amazonbot,
# Applebot-Extended, Bytespider, CCBot, ClaudeBot, Google-Extended, GPTBot,
# meta-externalagent…) et un Content-Signal « ai-train=no ».
#
# DÉCISION DE LUCAS, 2026-08-22 : ouvrir le site aux robots d'IA.
# Motif : l'association cherche des clients. Être absente des réponses de
# ChatGPT, Claude, Perplexity ou des AI Overviews de Google à une question
# du type « qui fait de la captation vidéo à Antony » est un canal de
# visibilité perdu, et ce canal prend de l'importance.
#
# Vérifié le 22/08/2026 : ces robots n'étaient bloqués QUE par cette
# déclaration, jamais par le WAF (GPTBot, ClaudeBot et PerplexityBot
# recevaient tous un 200). L'ouverture se joue donc entièrement ici.
#
# COMMENT LES GROUPES CI-DESSOUS L'EMPORTENT sur ceux de Cloudflare :
# la RFC 9309 (§2.2.2) impose de fusionner les groupes qui visent le même
# user-agent, puis, pour une URL donnée, de retenir la règle la plus
# spécifique ; à spécificité égale, c'est la MOINS restrictive qui gagne.
# « Allow: / » et « Disallow: / » ont la même longueur, donc « Allow »
# l'emporte pour tout robot conforme.
#
# ⚠️ C'est un rattrapage, pas la solution propre. Tant que le bloc managé
# est actif, le fichier servi contient des directives contradictoires et
# reste illisible pour un humain. Le désactiver dans le dashboard
# Cloudflare (AI Crawl Control) est la vraie correction ; ce fichier est
# alors servi tel quel et devient la seule source de vérité.
#
# TOUJOURS vérifier le résultat réel avec `curl https://elkarec.fr/robots.txt`,
# jamais en lisant ce fichier seul.
# ─────────────────────────────────────────────────────────────────────────

# Content-Signal : la citation par les assistants est autorisée (c'est le
# canal de visibilité recherché), l'entraînement de modèles ne l'est pas.
# Pour ouvrir aussi l'entraînement, passer « ai-train » à « yes ».
User-agent: *
Content-Signal: search=yes,ai-input=yes,ai-train=no,use=reference
Allow: /
